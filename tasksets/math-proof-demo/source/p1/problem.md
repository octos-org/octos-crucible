# Problem (IMO 1959, Problem 1)

Prove that the fraction (21n + 4) / (14n + 3) is irreducible for every natural number n.

Write a complete, rigorous proof in the file `answer.md` in the current directory.

Source: International Mathematical Olympiad 1959, Problem 1 (https://www.imo-official.org/problems.aspx).
