# 数据与隐私

## 提交前的声明

每次提交评测前，你需要勾选同意以下声明，否则无法提交：

> 你上传的内容、评测产出和日志会加密后永久保存，我们会用于研究和改进平台。你的模型 key 和下载密码在评测结束后立即删除，不会保存。

下面解释这段话具体意味着什么。

## 哪些东西会保存，怎么保存

你上传的 agent 包或产出、agent 在每个阶段做出的产出、运行日志，都会用平台的公钥加密后永久保存。加密在两个地方发生：你上传的文件在你的浏览器里就已经加密，上传到服务器的只有密文；评测过程中产生的产出和日志，在运行评测的机器上加密后才保存。保存的位置是本仓库的 GitHub Release，文件名是加密后内容的 SHA-256 哈希，从文件名和内容本身看不出任何信息。

能解密这些文件的私钥只存在两个地方：GitHub Actions 的加密配置（Secrets），供评测运行时使用；以及管理员的密码管理器，作为备份，并在研究时使用。接收你上传的网页后端（Cloudflare Worker）不持有私钥，看不到明文。

我们会用这些数据研究 coding agent 的行为、改进平台和题目。

## 谁能看到什么

你的产出和日志不公开，只有你自己能通过下载密码取回（见 [results.md](results.md)），以及管理员在研究时用私钥解密。

分数和统计数据（每个阶段的分数、用时、请求数、token、缓存命中率、等价花销）默认不公开，只有你自己在“我的评测”里能看到。提交时如果打开“公开分数”开关，这些数字连同题目包名、agent 名称和版本、模型名、你的 GitHub 用户名会以明文形式发布到本仓库的 `data` 分支，任何人都可以查看（产出和日志在其中只以加密文件的哈希出现）。产出和日志无论如何都不公开。在网页上浏览公开分数的页面即将推出。

每次评测都在本仓库的 GitHub Actions 上运行，运行记录是公开的。这些日志里只有进度（例如进行到哪个阶段）和数字，agent 自己的输出写在单独的日志文件里，加密后保存，不出现在公开日志中。你的模型 key、接口地址、下载密码也都不会出现在公开日志里。

## 模型 key 如何处理

你在网页上填写的 API key、接口地址和下载密码，会在你的浏览器里用平台公钥加密成一个整体，再提交给后端。后端看不到明文，只把这段密文存入 Cloudflare Workers KV，并设置 24 小时自动过期。

评测运行时，GitHub Actions 用私钥解开这段密文，把 key 通过标准输入直接交给计量代理，不写入文件、不放进环境变量、不出现在日志里。agent 所在的容器里只有一个假的 key（`dummy`），所有模型请求都经过计量代理，由代理换上你的真实 key 再转发到你填的接口。计量代理只会转发到你填写的那个地址，并且只允许你填写的那个模型名。在构建 agent 镜像的阶段，机器上还没有任何密钥。

评测结束后，key 和下载密码立即从 KV 删除。即使删除这一步因故没有执行，KV 的 24 小时过期也会把它们清掉。平台不保存任何形式的 key 或下载密码。

## 已知的残余风险

agent 在容器里运行，容器有严格的资源、权限和网络限制。但如果有人利用容器逃逸漏洞突破了隔离，理论上可以拿到那台机器上正在使用的模型 key 和私钥。平台的缓解措施是：每次评测使用一次性的机器，用完即弃；key 用完立即删除；平台的密钥对可以更换，更换后新文件都用新钥匙加密。如果你担心这一点，可以为评测单独创建一个 API key，设好额度，用完后在模型服务商那里作废。
