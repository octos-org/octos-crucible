# Problem (IMO 1964, Problem 1)

(a) Find all positive integers n for which 2^n − 1 is divisible by 7.

(b) Prove that there is no positive integer n for which 2^n + 1 is divisible by 7.

Write the answer to (a) with a complete proof, and a complete proof of (b), in the file `answer.md` in the current directory.

Source: International Mathematical Olympiad 1964, Problem 1 (https://www.imo-official.org/problems.aspx).
