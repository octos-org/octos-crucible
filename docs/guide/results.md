# 查看结果与下载产出

## 评测详情

提交成功后，网页会给出一个评测编号，并提供“查看评测”的链接。以后也可以在“我的评测”页面找到你提交过的所有评测，按提交时间倒序排列，每一项显示题目包、模型名（上传产出的评测显示“产出打分”）、提交时间、总分和状态。

评测的状态依次是：排队中、构建中（构建 agent 镜像）、某阶段进行中（例如“stage-2 进行中”）、打分中，最后是完成或失败。状态只会往前走。评测没结束时，详情页每 15 秒自动刷新一次。

详情页顶部是基本信息：评测编号、agent 名称和版本、提交时间、分数是否公开，以及一个指向 GitHub Actions 运行记录的链接。这个运行记录是公开的，但里面只有进度和数字，不包含 agent 的输出、你的代码或任何密钥，详见 [privacy.md](privacy.md)。

完成第一个阶段后，结果就开始显示，分三部分。“总览”给出整次评测的总分、用时、token（下面附请求数）、缓存命中率和等价花销；运行多遍时显示均值 ± 标准差和最低到最高的范围。“各阶段”表按阶段汇总，每行是一个阶段在所有遍上的分数、用时、请求数、token、缓存命中率和等价花销。最后是每一遍单独一张表，列出每个阶段通过了几项测试、结果标记、用时、请求数、输入和输出 token、缓存命中率、等价花销，以及合计。各项指标的含义和算法见 [README.md](README.md#结果里的各项指标)。

如果某一阶段的结果标记是“平台错误（不计分）”，说明是打分器自身出了故障，不是你的 agent 的问题，这一阶段不计入总分。

## 下载产出

评测完成后，详情页会出现“下载产出”按钮。下载到的是一个 zip，里面是这次评测的产出和日志，用你提交时设置的下载密码加密。

这个 zip 使用 AES-256 加密。macOS 的“归档实用工具”（双击解压）和 Windows 资源管理器自带的解压功能都不支持这种加密方式，打开时会报错或者提示文件损坏，这不是文件的问题。请使用以下任一工具：

- **7-Zip**（Windows，免费）：右键 zip，选择 7-Zip → 解压，输入下载密码。
- **Keka**（macOS，免费）：把 zip 拖到 Keka 上，输入下载密码。
- **The Unarchiver**（macOS，免费，App Store 可下载）：用它打开 zip，输入下载密码。

Linux 上可以用 `7z x 文件名.zip`（需要安装 p7zip 或 7zip 包）。命令行的 `unzip` 同样不支持 AES 加密。

为什么不用系统自带工具能打开的格式？系统自带工具只支持一种老的 zip 加密方式（ZipCrypto），这种方式早已被攻破，有现成的工具可以在不知道密码的情况下解开文件。你的产出可能包含 agent 写出的完整代码和运行日志，我们不想用一种形同虚设的加密来保护它，所以只提供 AES-256。

下载密码在评测结束后就从平台删除了，平台不保存它，也无法帮你找回。如果忘了密码，这份 zip 就打不开了。提交时请把密码记在密码管理器里。
